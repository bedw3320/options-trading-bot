# Non-Trade Activities for Option Events

> **Source:** https://docs.alpaca.markets/docs/non-trade-activities-for-option-events
> **Last scraped:** 2026-03-06
> **Relevance:** Activity types generated by option exercise, assignment, and expiration — critical for understanding post-trade state and position reconciliation.

---

## Activity Types

| Activity Type | Trigger | Description |
| --- | --- | --- |
| `OPEXC` | Exercise | Removes the option position |
| `OPASN` | Assignment | Removes the option position |
| `OPEXP` | Expiration (OTM) | Flattens the expired position |
| `OPTRD` | Exercise or Assignment | The paired underlying stock trade |

---

## Option Exercise (`OPEXC` + `OPTRD`)

Exercise removes the option and generates an underlying stock trade.

```json
[
  {
    "activity_type": "OPEXC",
    "date": "2023-07-21",
    "net_amount": "0",
    "description": "Option Exercise",
    "symbol": "AAPL230721C00150000",
    "qty": "-2",
    "status": "executed"
  },
  {
    "activity_type": "OPTRD",
    "date": "2023-07-21",
    "net_amount": "-30000",
    "description": "Option Trade",
    "symbol": "AAPL",
    "qty": "200",
    "price": "90",
    "status": "executed"
  }
]
```

2 contracts exercised → 200 shares purchased at $150 strike. Net amount = $150 × 200 = $30,000.

---

## Option Assignment (`OPASN` + `OPTRD`)

Assignment removes the option and generates an obligation trade.

```json
[
  {
    "activity_type": "OPASN",
    "date": "2023-07-01",
    "net_amount": "0",
    "description": "Option Assignment",
    "symbol": "AAPL230721C00150000",
    "qty": "2",
    "status": "executed"
  },
  {
    "activity_type": "OPTRD",
    "date": "2023-07-01",
    "net_amount": "30000",
    "description": "Option Trade",
    "symbol": "AAPL",
    "qty": "-200",
    "price": "150",
    "status": "executed"
  }
]
```

2 contracts assigned → 200 shares **sold** at $150 strike (call assignment = obligation to sell).

## ITM Option Expiry

If an ITM option expires without a DNE (do not exercise) instruction:
- **Sufficient BP/shares:** Alpaca auto-exercises
- **Insufficient BP/shares:** Alpaca auto-liquidates the position before close

---

## OTM Option Expiry (`OPEXP`)

```json
[
  {
    "activity_type": "OPEXP",
    "date": "2023-07-21",
    "net_amount": "0",
    "description": "Option Expiry",
    "symbol": "AAPL230721C00150000",
    "qty": "-2",
    "status": "executed"
  }
]
```

OTM contract flattened, no underlying trade generated.

---

## Key Notes for the Bot

- Monitor `OPASN` events to detect unexpected assignments (can happen overnight on short positions)
- `OPTRD` net_amount sign: negative = cash outflow (bought stock), positive = cash inflow (sold stock)
- Exercise via API: `POST /positions/{symbol_or_contract_id}/exercise` (see `reference/option-exercise.md`)
- DNE via API: `POST /positions/{symbol_or_contract_id}/do-not-exercise`
